# Day 14 – Higher Lower Game Project
## Overview

This project implements a simple Higher Lower game, where players compare data points and guess which option has a higher value. The focus of this exercise is on applying core Python concepts in a practical and interactive way.

## Concepts Practiced
- Working with dictionary data structures
- Writing and organizing functions (procedures)
- Implementing conditional logic for game flow
## Project Description

The Higher Lower Game challenges users to make comparisons between two options and determine which one ranks higher based on predefined data. The game continues as long as the user provides correct answers, reinforcing logical thinking and control flow in Python.
